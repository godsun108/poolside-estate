# Poolside Margarita — Manufacturer RFQ v0.1

**Status:** Research RFQ. No production commitment.

## Project
Poolside Estate is evaluating contract development and manufacturing for a premium tequila-based ready-to-drink Margarita for an initial U.S. launch.

## Working product brief
- Spirit base: authentic tequila
- Cocktail: Margarita
- Profile: lime-forward, restrained sweetness, clean finish
- ABV: not final; please quote feasible options around 8–12.5% if practical
- Format under evaluation: 8 oz and/or 12 oz aluminum can
- Still vs lightly carbonated: both under evaluation
- Pack: likely 4-pack initially
- Formula: development required / open to partner formulation support
- Initial geography: Florida under evaluation
- Brand: working brand only; trademark clearance underway

## Please provide
### Facility & compliance
1. Legal company/facility name and address.
2. TTB DSP permit number and relevant state licenses.
3. Experience producing tequila-based RTDs.
4. Whether you support TTB formula and COLA submissions.
5. Whether you can source tequila or accept customer-specified tequila.
6. Whether tequila can be sourced from a named NOM / producer.

### Development
7. Formulation/development fee.
8. Number of included bench rounds.
9. Pilot/batch capability and minimum.
10. Shelf-life/stability testing available.
11. Still and carbonated capabilities.
12. Real juice / lime juice handling constraints.
13. Stabilization process used.

### Production
14. Minimum commercial run by SKU.
15. Available can sizes.
16. Printed-can vs sleeved/pressure-sensitive label minimums.
17. Case-pack options.
18. Conversion/co-pack fee.
19. Indicative all-in finished-goods cost if you source inputs.
20. Pricing at approximately 2,500 / 10,000 / 25,000 24-can-equivalent cases if supported.
21. Deposit/payment terms.
22. Current production lead time.
23. Packaging/component lead time.

### Logistics & QA
24. Warehousing options and rates.
25. Distributor pickup / freight options.
26. QA program and COA availability.
27. Recall procedure.
28. Product/liquor liability insurance requirements.
29. Finished-product retain sample policy.
30. References for comparable spirit-based RTD projects, if available.

## Requested response format
Please distinguish:
- one-time development/setup fees;
- per-unit variable costs;
- Poolside-supplied inputs;
- manufacturer-supplied inputs;
- taxes not included;
- freight not included;
- MOQ and lead time.
