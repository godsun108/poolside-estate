## Commercial waterfall
For each proposed MSRP:
1. Consumer MSRP
2. retailer economics
3. distributor economics
4. net revenue to Poolside
5. landed COGS
6. variable selling/depletion expense
7. contribution dollars
8. contribution margin %
9. cash required for MOQ
10. estimated cash conversion cycle

## Do not confuse
- **gross margin** with contribution margin;
- distributor sell-in with consumer depletion;
- first production MOQ with total launch cash;
- ex-factory cost with landed cost;
- suggested retail price with actual realized net revenue.

## Investment-gate outputs
Before G5 passes, family should be able to answer:
- How much cash is at risk before first sale?
- How much cash is needed before first reorder?
- Contribution dollars per case?
- Break-even cases excluding founder salaries?
- Sensitivity if freight +20%?
- Sensitivity if distributor allowance +5 pts?
- Sensitivity if COGS +10%?
- What happens if first run takes 2× expected time to sell?
