# Research Register

This directory is for evidence-backed diligence. Every material claim should eventually include a primary source, retrieval date, and a note distinguishing confirmed facts from working assumptions.

1. Trademark/name clearance
2. RTD margarita category and competitive set
3. Tequila sourcing and certification
4. Co-packer / contract manufacturing landscape
5. TTB formula and label pathway
6. State launch/licensing strategy
7. Distribution options and three-tier implications
8. Unit economics and working-capital requirements
9. Family ownership/governance professional review
10. Zero-proof extension opportunity

## Evidence labels
- **CONFIRMED** — supported by primary/authoritative source.
- **WORKING ASSUMPTION** — useful for modeling but not yet verified.
- **PROPOSAL** — strategic recommendation.
- **COUNSEL REVIEW** — legal/tax/regulatory item requiring professional validation.
